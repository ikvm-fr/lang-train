# lang-train

A browser-based pronunciation trainer: a phrase plays → a pause for you to repeat it → the next phrase.
Runs entirely in the frontend (PWA), including with the screen off.

- Site: https://ikvm-fr.github.io/lang-train/
- Branch previews: `https://ikvm-fr.github.io/lang-train/preview/<branch>/` (`/` in a branch name becomes `-`)

## Development

```bash
npm install
npm run dev        # local dev server
npm run build      # type check + build into dist/
```

Deployment is handled by [.github/workflows/pages.yml](.github/workflows/pages.yml): every push is built and
published to the `gh-pages` branch. GitHub Pages must be set to serve `gh-pages` / `(root)`.

## Pack format (provisional, prototype)

A ZIP archive:

```
phrases.csv        required; UTF-8 or cp1251
pack.json          optional: { "id": "...", "title": "..." }
audio/001.mp3 ...  paths are listed in phrases.csv
```

`phrases.csv` columns: `file,text,translation,transcription,notes` (only `file` is required).

Example: `public/demo/demo.zip`, generated by `scripts/make-demo-pack.sh` (espeak-ng + ffmpeg).

Preparing a pack in Audacity: mark phrases with labels → *Export Multiple* (split by labels, numbered) →
fill in a spreadsheet in Google Sheets → download as CSV → zip everything together.

## How playback works

`src/engine/Player.ts` is a React-independent engine. Phrases and pauses are scheduled ahead of time on the
`AudioContext` timeline (~30 s ahead), so timers throttled in the background cannot break the pauses.
The media session keeps the app alive in the background (either a silent `<audio>` track alongside, or
routing the output through an `<audio>` stream; switchable in the settings for testing).

Headset / notification buttons: ⏯ pause, ⏭ next phrase, ⏮ one more repeat of the current phrase.
